# Portal Educativo de Métodos Numéricos 

Bienvenido al repositorio oficial del **Módulo de Ecuaciones No Lineales y Errores**. 

Las matemáticas avanzadas y el cálculo numérico a menudo parecen un lenguaje exclusivo para ingenieros o programadores. Este proyecto nace con un propósito claro: **democratizar el conocimiento matemático**. Hemos diseñado esta plataforma web pensando en estudiantes de ciencias sociales, ciudadanos curiosos y cualquier persona sin conocimientos previos de programación. Aquí, resolver ecuaciones complejas deja de ser una caja negra y se convierte en una experiencia visual, guiada y paso a paso.

## Características Principales

Nuestra plataforma traduce algoritmos complejos en herramientas amigables y comprensibles:

* **Interfaz Intuitiva:** Un diseño limpio que guía al usuario desde la teoría básica hasta la resolución práctica sin abrumarlo con tecnicismos.
* **Resolución Paso a Paso:** Al ingresar una ecuación, el sistema no solo escupe un resultado; genera una tabla detallada mostrando cada iteración para que el usuario comprenda cómo la computadora "piensa" y se acerca a la respuesta.
* **Gráficas Interactivas:** Visualización dinámica de las funciones matemáticas para entender visualmente dónde se cruzan las líneas y qué significa encontrar una "raíz".
* **Dos Métodos Poderosos:**
  * **Bisección:** El método más seguro e intuitivo, ideal para entender el concepto de acorralar una respuesta cortando un intervalo por la mitad.
  * **Newton-Raphson:** Un método avanzado y veloz que demuestra el poder de las matemáticas modernas para encontrar soluciones en fracciones de segundo.
* **Tolerancia a Errores de Usuario:** El sistema comprende cómo escriben las personas normalmente (por ejemplo, acepta `3x` y lo traduce automáticamente para la computadora), e incluye alertas amigables si se ingresan datos imposibles de calcular.

## 🚀 Instrucciones de Uso

No requiere instalaciones complejas, descargas de software pesado ni conocimientos de consola. 

1. **Descargar y Ejecutar:** Descarga el código de este repositorio y abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Firefox, Edge, Safari).
2. **Explorar la Teoría:** Navega por la sección de "Teoría" para familiarizarte con los conceptos básicos explicados en lenguaje sencillo.
3. **Usar la Calculadora:** 
   * Dirígete a la sección de calculadoras.
   * Ingresa tu función matemática (por ejemplo: `x^3 - x - 2`).
   * Establece un intervalo de búsqueda o un punto de inicio.
   * Haz clic en "Calcular Raíz" y observa cómo se genera la solución paso a paso.
4. **Practicar:** Utiliza la sección de "Ejercicios Resueltos" y "Autoevaluación" para poner a prueba lo aprendido.

## 🛠️ Tecnologías Utilizadas

Este proyecto fue construido utilizando tecnologías web estándar, garantizando que funcione en cualquier dispositivo sin requerir servidores externos:

* **HTML5:** Estructuración semántica del contenido.
* **CSS3:** Diseño responsivo, colores amigables y adaptabilidad a dispositivos móviles.
* **JavaScript (Vanilla):** Motor lógico puro para el cálculo de derivadas, iteraciones numéricas y validación de errores.
* **Chart.js:** Librería ligera para la renderización de las gráficas matemáticas interactivas.
