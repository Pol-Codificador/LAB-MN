📝 EJERCICIOS RESUELTOS — MÓDULO 1

Ecuaciones No Lineales y Métodos Numéricos

En esta sección se presentan ejercicios resueltos paso a paso utilizando los métodos de Bisección y Newton-Raphson.

📊 1. Ejercicio resuelto — Método de Bisección

Encontrar una raíz aproximada de la función:

f(x) = x³ − x − 2

utilizando el método de Bisección, considerando el intervalo inicial [1, 2] y una tolerancia:

ε = 10⁻⁶

🔹 Paso 1. Verificar el intervalo inicial

Primero evaluamos la función en los extremos del intervalo:

Para x = 1:
f(1) = (1)³ − 1 − 2 = −2
Para x = 2:
f(2) = (2)³ − 2 − 2 = 4

Como los signos son diferentes, se cumple:

f(1) · f(2) < 0

Por lo tanto, existe al menos una raíz dentro del intervalo [1, 2], considerando que la función es continua.

🔹 Paso 2. Calcular el punto medio

El punto medio del intervalo se calcula mediante:

c = (a + b) / 2

Para la primera iteración:

c = (1 + 2) / 2 = 1.5

🔹 Paso 3. Evaluar la función en el punto medio

f(1.5) = (1.5)³ − 1.5 − 2
f(1.5) = −0.125

Como f(1.5) es negativo y f(2) es positivo, el nuevo intervalo será:

[1.5, 2]

🔹 Paso 4. Continuar con las iteraciones

El mismo procedimiento se repite en cada iteración: se calcula el punto medio, se evalúa la función y se selecciona el subintervalo que conserva el cambio de signo.

🔹 Paso 5. Criterio de parada

El proceso continúa reduciendo el tamaño del intervalo hasta que el error estimado sea menor que la tolerancia establecida:

Error ≤ 10⁻⁶

Debido a que el intervalo inicial tiene una longitud de 1, se requieren aproximadamente 20 iteraciones para alcanzar una precisión del orden de 10⁻⁶.

✅ Resultado del método de Bisección

La raíz aproximada obtenida es:

x ≈ 1.5213797068

📈 2. Ejercicio resuelto — Método de Newton-Raphson

Resolver aproximadamente la misma ecuación:

f(x) = x³ − x − 2

utilizando el método de Newton-Raphson, con:

x₀ = 1.5
ε = 10⁻⁶

🔹 Paso 1. Calcular la derivada

Para aplicar Newton-Raphson necesitamos calcular la derivada de la función:

f′(x) = 3x² − 1

🔹 Paso 2. Escribir la fórmula

La fórmula del método de Newton-Raphson es:

xn+1 = xn − f(xn) / f′(xn)

🔹 Paso 3. Primera iteración

Partimos de:

x₀ = 1.5

Evaluamos la función:

f(1.5) = (1.5)³ − 1.5 − 2
f(1.5) = −0.125

Calculamos la derivada:

f′(1.5) = 3(1.5)² − 1
f′(1.5) = 5.75

Ahora aplicamos la fórmula:

x₁ = 1.5 − (−0.125 / 5.75)
x₁ ≈ 1.5217391304

🔹 Paso 4. Segunda iteración

Utilizamos ahora:

x₁ = 1.5217391304

Evaluamos nuevamente la función y su derivada:

f(1.5217391304) ≈ 0.002138
f′(1.5217391304) ≈ 5.947073

Aplicando nuevamente la fórmula:

x₂ = x₁ − f(x₁) / f′(x₁)
x₂ ≈ 1.5213797

🔹 Paso 5. Continuar las iteraciones

Al continuar con el mismo procedimiento, las aproximaciones se acercan rápidamente a la raíz.

n xₙ f(xₙ) |xₙ₊₁ − xₙ|
0 1.5000000000 -0.125000 0.0217391304
1 1.5217391304 0.002138 0.0003594
2 1.5213797... ≈ 10⁻⁶ – 10⁻⁷ ≈ 10⁻⁷

🔹 Paso 6. Criterio de parada

El proceso continúa hasta que la diferencia entre dos aproximaciones consecutivas sea suficientemente pequeña:

|xn+1 − xn| < ε

En este ejercicio se utiliza:

ε = 10⁻⁶

✅ Resultado del método de Newton-Raphson

La raíz aproximada obtenida es:

x ≈ 1.5213797

El método alcanza la solución en pocas iteraciones.

🔎 3. Comparación de los métodos

Ambos métodos permiten encontrar una aproximación de la raíz de la ecuación, pero utilizan procedimientos diferentes.

Característica Bisección Newton-Raphson
Función Necesaria Necesaria
Derivada No necesita Necesita
Valor inicial Intervalo [a,b] Un valor x₀
Cambio de signo Necesario No es requisito del método
Velocidad de convergencia Más gradual Puede ser muy rápida cerca de la raíz
Ejemplo estudiado ≈ 20 iteraciones ≈ 3–4 iteraciones

📌 4. Conclusión

En ambos ejercicios se obtuvo aproximadamente la misma raíz para la ecuación:

x³ − x − 2 = 0

La solución aproximada encontrada es:

x ≈ 1.5213797

El método de Bisección trabaja reduciendo progresivamente el intervalo donde se encuentra la raíz. Por otro lado, Newton-Raphson utiliza la derivada para generar nuevas aproximaciones a partir de un valor inicial.

Estos ejercicios permiten observar cómo diferentes métodos numéricos pueden llegar a una misma solución aproximada utilizando procedimientos distintos.
