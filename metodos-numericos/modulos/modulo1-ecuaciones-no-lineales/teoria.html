Ecuaciones No Lineales

En esta sección se presentan los conceptos fundamentales necesarios para comprender los métodos numéricos utilizados en la resolución de ecuaciones no lineales.

🎯 1. Objetivo del módulo

Comprender los fundamentos de los métodos numéricos para encontrar soluciones aproximadas de ecuaciones no lineales.

📊 2. Método de Bisección

El método de Bisección es un método numérico utilizado para encontrar una raíz de una función dentro de un intervalo.

Para aplicar el método se parte de un intervalo [a,b] en el que la función cambia de signo.

Condición inicial

f(a) · f(b) < 0

Esta condición indica que existe al menos una raíz dentro del intervalo cuando la función es continua.

Fórmula del punto medio

En cada iteración se calcula el punto medio del intervalo:

c = (a + b) / 2

Actualización del intervalo

Después de calcular c, se evalúa el signo de la función y se conserva el subintervalo donde se mantiene el cambio de signo.

Criterio de parada

El proceso puede detenerse cuando el error estimado sea menor que la tolerancia establecida o cuando se alcance el número máximo de iteraciones.

📈 3. Método de Newton-Raphson

El método de Newton-Raphson permite aproximar una raíz de una función utilizando la función y su derivada.

Fórmula

xn+1 = xn − f(xn) / f′(xn)

Interpretación

A partir de una aproximación inicial x₀, el método calcula sucesivas aproximaciones que buscan acercarse a la raíz de la función.

Condición importante

La derivada debe poder evaluarse en los puntos utilizados durante el proceso y no debe ser cero en el denominador.

Criterio de parada

Las iteraciones pueden detenerse cuando la diferencia entre aproximaciones sucesivas sea suficientemente pequeña o cuando se alcance la tolerancia establecida.
