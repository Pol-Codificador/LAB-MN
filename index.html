Inicio

Bienvenido al módulo de Integración Numérica. Este módulo te permite calcular una cantidad acumulada (como el volumen de datos en MB) a partir de una tasa de transferencia variable en el tiempo, utilizando el método del Trapecio Compuesto.

Teoría Breve: Trapecio Compuesto

El método consiste en dividir el intervalo de tiempo en n tramos iguales. En cada tramo, se aproxima la curva de la función con una línea recta, formando un trapecio. La suma de todas estas áreas nos da una estimación del volumen total.

Fórmula del paso: h = (x₁ − x₀) / n

Calculadora: Método del Trapecio

Función de tasa: r(t) = a·t² + b·t + c (MB/s)

Ejemplo de Referencia

Si evaluamos la tasa r(t) = t² + 1 entre 0 y 2 segundos con 4 subintervalos, el resultado manual esperado es 4.75 MB con un tamaño de paso h = 0.5 s. (Inténtalo en la calculadora de arriba).
